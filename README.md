# data-encryption-visualiser-remake
A first year university project rebuilt as a personal learning project, using vanilla HTML, CSS, and JavaScript to visualise how encryption algorithms like the Caesar cipher, Vigenère cipher, and Substitution cipher work step by step.

Open `index.html` to run it — see [docs/README.md](docs/README.md) for how to serve it locally (it needs `http://`, not a plain double-click). For the project's vision, scope, and architecture, see [docs/](docs/).
